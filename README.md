# ربات هوش مصنوعی تلگرام (چت + ساخت عکس)

این ربات با پایتون نوشته شده، برای پاسخ‌دهی هوشمند از مدل‌های OpenAI (GPT) و برای ساخت عکس از DALL·E استفاده می‌کند.

## امکانات
همه چیز با **دکمه** انجام می‌شود، نه دستور اسلش:
- چت آزاد: هر پیامی بفرستی، جواب هوشمند می‌گیری (با حافظه‌ی چند پیام آخر)
- دکمه‌ی «🎨 ساخت عکس» → بعدش توضیح عکس مورد نظرت رو بنویس تا با DALL·E ساخته بشه
- دکمه‌ی «🔄 شروع گفتگوی جدید» → پاک کردن حافظه گفتگو
- دکمه‌ی «❓ راهنما» → توضیح نحوه استفاده

تنها با فرستادن `/start` (یک‌بار، در ابتدا) منوی دکمه‌ها زیر صفحه چت ظاهر می‌شود.

## مرحله ۱: گرفتن توکن‌های لازم

### توکن ربات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بزن و مراحل را طی کن (اسم و یوزرنیم ربات را انتخاب کن).
3. یک توکن شبیه این می‌گیری: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### کلید API اوپن‌ای‌آی
1. به [platform.openai.com/api-keys](https://platform.openai.com/api-keys) برو و وارد شو.
2. یک API Key جدید بساز.
3. حتماً باید حساب OpenAI اعتبار (Billing) داشته باشد تا GPT و DALL·E کار کنند.

## مرحله ۲: نصب و اجرا (روی کامپیوتر خودت، برای تست)

```bash
cd telegram_ai_bot
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

حالا فایل `.env` را باز کن و مقادیر واقعی توکن‌ها را جایگزین کن:
```
TELEGRAM_BOT_TOKEN=توکن_واقعی_ربات
OPENAI_API_KEY=کلید_واقعی_اوپن_ای_آی
```

سپس اجرا کن:
```bash
python bot.py
```

حالا در تلگرام سراغ ربات خودت برو و `/start` را بزن.

⚠️ نکته: تا وقتی این اسکریپت روی کامپیوترت در حال اجراست، ربات فعال است. اگر کامپیوتر را خاموش کنی یا برنامه را ببندی، ربات از کار می‌افتد.

## مرحله ۳: میزبانی دائمی (Hosting) — برای اینکه ربات ۲۴ ساعته روشن بماند

چون گفتی مطمئن نیستی، چند گزینه به ترتیب سادگی:

### گزینه ۱ (ساده‌ترین، برای شروع): Railway.app یا Render.com
- هر دو نسخه رایگان/ارزان دارند و اجرای یک اسکریپت پایتون ساده است.
- کافیه پروژه را در یک ریپازیتوری گیت‌هاب بذاری، بعد در Railway/Render وصلش کنی، و متغیرهای محیطی (`TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`) را در پنل تنظیمات آن سرویس وارد کنی.
- دستور اجرا (Start Command): `python bot.py`

### گزینه ۲ (کنترل کامل، کمی فنی‌تر): یک VPS ارزان
- سرویس‌هایی مثل Hetzner، DigitalOcean یا Arvan Cloud یک سرور لینوکسی ارزان (ماهی چند دلار) می‌دهند.
- روی سرور، پایتون و پروژه را نصب می‌کنی و با ابزاری مثل `screen`، `tmux` یا `systemd` آن را به‌صورت دائمی در پس‌زمینه اجرا می‌کنی تا با قطع اتصال SSH خاموش نشود.

### گزینه ۳: PythonAnywhere
- برای پروژه‌های کوچک پایتون مناسب است و راه‌اندازی نسبتاً ساده‌ای دارد.

اگر بخوای، می‌تونم مرحله به مرحله راهنماییت کنم که همین پروژه رو مثلاً روی Railway یا یک VPS بالا بیاری — فقط بگو کدوم گزینه رو ترجیح می‌دی.

## مرحله ۴ (رایگان روی Render): راه‌اندازی کامل

چون Render پلن رایگان فقط برای «Web Service» داره (نه Background Worker)، و Web Service رایگان بعد از ۱۵ دقیقه بی‌فعالیتی خاموش می‌شه، کد ربات (`bot.py`) از قبل یک سرور HTTP کوچک داره که به رندر نشون می‌ده «فعاله». برای بیدار نگه داشتنش هم باید یه سرویس رایگان مثل UptimeRobot هر چند دقیقه یک‌بار بهش سر بزنه.

### ۴.۱- گذاشتن پروژه روی گیت‌هاب
1. یک ریپازیتوری جدید در [github.com](https://github.com) بساز (می‌تونه Private باشه).
2. پوشه‌ی `telegram_ai_bot` را در آن پوش (push) کن. **فایل `.env` را push نکن** — همین الان یک `.gitignore` توی پروژه هست که جلوی این کار رو می‌گیره.

```bash
cd telegram_ai_bot
git init
git add .
git commit -m "اولین نسخه ربات"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### ۴.۲- ساخت سرویس در Render
1. وارد [dashboard.render.com](https://dashboard.render.com) شو (با گیت‌هاب می‌تونی وارد بشی).
2. روی **New +** بزن و **Web Service** را انتخاب کن.
3. ریپازیتوری گیت‌هابت را وصل کن.
4. تنظیمات:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: **Free**
5. در بخش **Environment Variables** این دوتا رو اضافه کن (مقدار واقعی توکن‌هات، نه چیزی که اینجا نوشته شده):
   - `TELEGRAM_BOT_TOKEN` = توکن ربات از BotFather
   - `OPENAI_API_KEY` = کلید API از OpenAI
6. روی **Create Web Service** بزن. رندر شروع به بیلد و اجرای ربات می‌کنه.
7. بعد از اتمام دیپلوی، یک آدرس مثل `https://your-bot-name.onrender.com` می‌گیری — همین آدرس نشون‌دهنده‌ی سلامت سرویسه (اگه بازش کنی، پیام «ربات فعال است ✅» رو می‌بینی).

### ۴.۳- بیدار نگه داشتن سرویس (جلوگیری از Sleep)
1. یک حساب رایگان در [UptimeRobot](https://uptimerobot.com) بساز (یا سرویس مشابه مثل cron-job.org).
2. یک Monitor جدید از نوع **HTTP(s)** بساز و آدرس رندرت (`https://your-bot-name.onrender.com`) رو بهش بده.
3. فاصله‌ی زمانی (Interval) رو روی **۵ تا ۱۰ دقیقه** بذار (کمتر از ۱۵ دقیقه، وگرنه سرویس می‌خوابه).
4. ذخیره کن. از این به بعد، این سرویس هر چند دقیقه یک‌بار به آدرس ربات سر می‌زنه و نمی‌ذاره بخوابه.

### ۴.۴- تست نهایی
حالا در تلگرام برو سراغ ربات خودت، `/start` رو بزن و امتحانش کن.

**نکته:** این روش رایگانه ولی صد‌درصد تضمین‌شده نیست — گاهی به‌خاطر محدودیت‌های زیرساخت Render، سرویس رایگان با کمی تاخیر (چند ثانیه تا حداکثر یکی-دو دقیقه) واکنش نشون بده. اگه دیدی این تاخیرها اذیت‌کننده‌ست، می‌تونی بعداً با یک کلیک به پلن Starter (۷ دلار/ماه) ارتقا بدی تا همیشه و بدون تاخیر روشن بمونه.

## نکات مهم
- مصرف API های OpenAI (چه GPT چه DALL·E) هزینه دارد؛ حتماً حد مصرف (Usage limit) در پنل OpenAI تنظیم کن تا هزینه غیرمنتظره نداشته باشی.
- فایل `.env` را هرگز در جایی عمومی (مثل گیت‌هاب عمومی) آپلود نکن، چون توکن‌هایت لو می‌رود.
